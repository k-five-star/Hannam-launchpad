# Hannam Launchpad

한국어 밈 사운드패드 초안. 빌드나 외부 JavaScript 의존성 없는 정적 웹 앱입니다.

## 실행

```sh
python3 -m http.server 8000
```

패드 클릭 또는 Q W E R / A S D F / Z X C V로 재생, ESC로 정지합니다. 8단계 시퀀서와 BPM/볼륨 조절을 제공합니다. 기본 음성은 브라우저 한국어 TTS이며 실제 밈 원본 음성이 아닙니다. 각 패드의 음성 교체 버튼으로 로컬 음성 파일을 사용할 수 있습니다. 파일은 서버로 업로드하지 않으며 새로고침하면 초기화됩니다. 합성음성은 브라우저에 따라 억양이 다르고 동시 재생하지 않습니다. 사용자 음성 파일은 동시 재생합니다.

## 배포
GitHub Pages에서 main 브랜치 루트(`/`)를 소스로 지정합니다. 저장소 공개 여부는 변경하지 않습니다.
